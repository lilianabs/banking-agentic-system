# Agentic banking system

This repo contains the code of a multi-agent banking system.

## Multi-agent system

This multi-agentic system consist of the following agents:

- **Coordinator:** This agent selects which subagent should perform the task according to the user's query.
- **Accounts:** Explains the process of getting a credit limit increase.
- **Transations:** Retrieves the latest n transations and provides statements per request.
- **Service:** Updates the customer's address.
